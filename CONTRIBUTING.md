# Contributing

Thanks for your interest in improving the Prime Number Checker! Small fixes, documentation improvements, and beginner-friendly feature ideas are welcome.

## Getting started

1. Fork the repository on GitHub.
2. Clone your fork and create a branch for your change.
3. Make the change and build the program:

   ```sh
   gcc -std=c11 -Wall -Wextra -pedantic prime.c -o prime
   ```

4. Run the program and check at least a prime number (such as `7`) and a non-prime number (such as `8`). Also check a number less than 2.
5. Commit your changes and open a pull request describing what you changed and how you tested it.

## Contributions

- Keep changes focused and explain user-visible changes in the README.
- Avoid adding dependencies unless they are needed.
- Include clear steps to reproduce any bug you report.
- For a larger feature, open an issue first so the approach can be discussed.

## Finding contributors

If you are new to GitHub, label small, clearly scoped tasks as **good first issue** in the repository's Issues tab. Share the repository link with classmates or relevant programming communities, and invite collaborators from **Settings → Collaborators** when you want to grant direct repository access.
